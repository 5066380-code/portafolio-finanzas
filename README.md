## Uso rápido
1. Sube toda la carpeta a un hosting estático (o ábrela localmente con un servidor).
2. Para personalizar sin código: pulsa **"Editar portafolio"** (esquina superior derecha).
   - Cambia textos, datos, fotografía, presupuesto (ingresos/gastos/ahorro) y totales se recalculan.
   - Usa **Guardar cambios**, **Cancelar**, **Restablecer** (con confirmación).
3. Los cambios se guardan en `localStorage` del navegador actual.
4. Usa **Exportar mis datos** (JSON) y **Importar mis datos** para respaldo/transferencia.
5. La fotografía puede guardarse en `assets/` y referenciarse; el respaldo JSON **no garantiza** guardar archivos binarios grandes entre dispositivos.

## Publicar en Google Sites
Google Sites **no importa carpetas completas**. Debes publicar este sitio en una URL pública (Netlify/Pages/etc.) e insertar con **Insertar > URL** o **Embed** según tu cuenta. 
- Algunas restricciones de iframe pueden aplicar; funciona mejor con URL directa.
- Los cambios guardados en localStorage son del navegador/dispositivo; no se sincronizan automáticamente con Google Sites.
